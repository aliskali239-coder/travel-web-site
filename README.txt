WANDER NOTES — TRAVEL BLOG WEBSITE

Included files:
- index.html: page structure and sample travel blog content
- style.css: responsive styling
- script.js: mobile navigation, read-story popups, and demo contact form

How to open:
1. Download and extract travel_blog_website.zip.
2. Open index.html in Chrome, Edge, or Firefox.
3. Internet is needed to load the sample photos and Google Fonts.

Features:
- Home hero section
- Travel blog cards with working “Read story” popups
- Destination list
- Travel tips
- About section
- Contact form demo
- Responsive mobile navigation

Note:
This is a front-end college project. The contact form displays a confirmation on the page but does not send messages to a server. You can edit the text and destination details in index.html.
